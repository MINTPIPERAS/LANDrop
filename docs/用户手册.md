# LANDrop 用户手册

**针对**：LANDrop 0.1.x（Windows 桌面版）

实验室只走通了账号密码路径，密钥路径后续还要在尝试，因为右边机子的SSH好像和windows更新冲突了，有特权分离问题，所以没有走通密钥路径。
报错：ssh_dispatch_run_fatal: ... Unknown error。（ssh9.5p1的问题 可以换个版本我会在安装包里面附带两个版本一个9.4一个9.5）
公钥本身已经被 sshd 成功识别并接受了。问题出在公钥验证通过之后：sshd 在准备完成认证流程时，它的特权分离子进程崩溃了。
个人建议如果展示机是有本地账户的话，优先走账号密码验证（这样装完LANDrop+SSH/SSHD就能直接用）。

## 一、基础准备

### 1. 发送端（装 LANDrop 的那台）

1. 双击 `LANDrop_0.2.0_x64-setup.exe` 安装。（不能联网的Win10及以下要用离线安装包 我会放在压缩包里面）
2. 出现「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」（大概率不会，工具主要是一些封装工作和网络链接操作）。
3. 启动 LANDrop，确认右上角显示「本机服务已连接」（作为发送端需要安装ssh客户端，接收端则是sshd即ssh服务器）。

> 接收端不需要安装 LANDrop。

### 2. 接收端（收文件的那台）

**Windows**（管理员 PowerShell）：

```powershell
# 安装并启动 SSH 服务（在Windows的系统-可选功能里面一般就有 如果没有可以用安装包msi 离线的 但是可能需要手动注册 最好是本机支持）
# 发送机一般不需要特别操作 因为win系统一般自带ssh客户端 只有接受端需要的sshd（ssh服务器）需要额外下载 msi安装包是两个拼一起的
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0 
Set-Service sshd -StartupType Automatic
Start-Service sshd

# 放行防火墙。规则已存在就跳过这条，只确认 Enabled=True、Profile=Any
New-NetFirewallRule -Name OpenSSH-Server-In-TCP -DisplayName 'OpenSSH SSH Server (sshd)' `
  -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22 -Profile Any

# 建目标目录（可选：LANDrop 会自动创建，包括多级子目录）
New-Item -ItemType Directory -Path 'D:\LANDrop' -Force
```

**Linux**（Linux系统的话原生支持所有ssh 而且都是通用账号系统 直接密码验证 几乎不会失败）：

```bash
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo ufw allow 22/tcp
mkdir -p ~/LANDrop
```

> 目标目录可预先建好，也可以不建——发送时会自动逐级创建。目录必须对当前账户可写。Windows 的目录在 LANDrop 里写成正斜杠，例如 `D:/LANDrop`。

### 3. 记下接收端的三项信息

**Windows**：
用户 + 主机指纹（非必须 是为防止被偷窃冒用密钥或是劫持链接）+ IP（需要同个网域 不要求联网 能ping通就没问题）
```powershell
whoami
ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ed25519_key.pub
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } |
  Select-Object InterfaceAlias, IPAddress
```

**Linux**：

```bash
whoami
hostname -I
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

- 用户名：Windows 取 `whoami` 反斜杠后半段，例如 `asus\asus` 取 `asus`。
- IP：选实际联网的网卡，忽略 VMware、VirtualBox 等虚拟网卡。
- 指纹：第 2、3 节在 LANDrop 里核对时要用。

## 二、密码认证

**只需要满足两个条件**：

1. 发送端能 SSH 连上接收端（sshd 在跑、防火墙放行、IP 正确）。能ssh链接即可（这个要在cmd不是powersshell）
2. 接收端用的是**本地账户**，并且该账户有密码。

判断账户类型，在接收端打开「设置 → 账户 → 你的信息」：

- 显示邮箱地址 = 微软账户，密码认证走不通，直接用第三节的密钥。
- 显示用户名 = 本地账户，可以用密码。（这个最方便）

一般规律：

- 企业机、专业版 Windows 上自己建的账户，通常是本地账户，可以用密码。
- 个人笔记本、家庭版 Windows 通常绑定微软账户，必须用密钥。

最直接的判断方式：在cmd，手动ssh链接一次：
```
ssh 用户名@接收端IP
```

！！！：输入密码能进，LANDrop 选「密码」就一定能用；进不去就需要改用密钥。

**操作步骤**：

1. 在 LANDrop 的「接收电脑设置」里填：
   - 对方电脑的 IP 地址：接收端 IP
   - 端口：`22`（一般不用改）
   - 对方电脑的用户名：接收端账户名（不是邮箱）
   - 文件保存到哪个文件夹：如 `D:/LANDrop`（不存在会自动创建）
2. 认证方式选「密码（推荐）」，输入接收端账户的密码。勾「记住密码（下次不用再输入）」会存进 Windows 凭据管理器，下次留空即可。
3. 点「验证对方电脑身份」，与接收端 `ssh-keygen -lf` 的输出核对一致后，点「确认验证」。
4. 点「保存这台电脑」。然后在「发送文件」里选文件，点「开始发送」，等状态变成「已完成」。

## 三、密钥认证

微软账户、家庭版个人笔记本，或者不想在接收端留密码时，用这种方式。

### 1. 发送端生成密钥

```bash
ssh-keygen -t ed25519 -f ~/.ssh/landrop_ed25519 -N "" -C "landrop@$(hostname)"
```

`-N ""` 不能少，LANDrop 不支持带口令的私钥。生成两个文件：

- `landrop_ed25519`：私钥，留在发送端，不给任何人。
- `landrop_ed25519.pub`：公钥，装到接收端。

查看公钥内容（复制整行）：

```bash
cat ~/.ssh/landrop_ed25519.pub
```

### 2. 发送端收紧私钥权限

```powershell
$key = Join-Path $env:USERPROFILE '.ssh\landrop_ed25519'
$acl = New-Object System.Security.AccessControl.FileSecurity
$acl.SetAccessRuleProtection($true, $false)
$me  = [System.Security.Principal.WindowsIdentity]::GetCurrent().Name
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule($me,'FullControl','Allow')))
Set-Acl -Path $key -AclObject $acl
```

### 3. 接收端安装公钥

先判断接收端账户是不是管理员（更建议两个地方都装上 省得判断）：

```powershell
whoami /groups | findstr /i "S-1-5-32-544"
```

**有输出（管理员账户）**：公钥装到 `C:\ProgramData\ssh\administrators_authorized_keys`

```powershell
$pubKey   = 'ssh-ed25519 AAAA...粘贴发送端的公钥整行...'
$authFile = 'C:\ProgramData\ssh\administrators_authorized_keys'

if (-not (Test-Path $authFile)) { New-Item -ItemType File -Path $authFile -Force | Out-Null }
Add-Content -Path $authFile -Value $pubKey -Encoding ascii

$acl = New-Object System.Security.AccessControl.FileSecurity
$acl.SetAccessRuleProtection($true, $false)
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule('BUILTIN\Administrators','FullControl','Allow')))
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule('NT AUTHORITY\SYSTEM','FullControl','Allow')))
Set-Acl -Path $authFile -AclObject $acl
```

**无输出（普通账户）**：公钥装到 `C:\Users\<用户名>\.ssh\authorized_keys`

```powershell
$pubKey   = 'ssh-ed25519 AAAA...粘贴发送端的公钥整行...'
$authFile = Join-Path $env:USERPROFILE '.ssh\authorized_keys'

New-Item -ItemType Directory -Path (Split-Path $authFile) -Force | Out-Null
Add-Content -Path $authFile -Value $pubKey -Encoding ascii
```

**Linux 接收端**：

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
echo 'ssh-ed25519 AAAA...发送端公钥...' >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### 4. LANDrop 里选私钥并发送

1. 「接收电脑设置」填 IP 地址、端口、用户名、保存位置。
2. 认证方式选「密钥文件」→「浏览」，选中 `C:\Users\<你>\.ssh\landrop_ed25519`。
   - 选**不带 `.pub`** 的那个文件。
   - 不能留空：`landrop_ed25519` 不是默认密钥名，留空找不到。
3. 点「验证对方电脑身份」，与接收端输出核对一致后，点「确认验证」。
4. 点「保存这台电脑」。然后在「发送文件」里选文件，点「开始发送」，等状态变成「已完成」。

## 四、日常使用补充

### 1. 给多台机器发

1. 侧栏「接收电脑」→「+」新建一台，填电脑名称、IP 地址、用户名、保存位置、认证方式。
2. 点设备行即可切换；每台设备的密码分开保存，不会互相覆盖。

### 2. 发多个文件或整个文件夹

1. 「发送文件」→「选择」可一次多选文件；右侧「选文件夹」按钮加整个目录。
2. 待发列表可逐项删除；点「开始发送 N 项」按顺序逐个发。
3. 某项失败不影响后续；结束后有「覆盖并重发」处理重名冲突。

### 3. 定时发送

1. 左下角「定时传输」→ 选来源（文件或文件夹）、目标设备、模式（一次性 / 每天 / 每周）、时间。
2. 点「添加任务」。应用开着时到点自动发；应用关着时由 Windows 计划任务执行。
3. 密码认证的设备必须先勾选「记住密码」，否则保存时会被拒绝。
4. 错过的任务会标「上次未执行」，点「立即执行」补发。

### 4. 日志与托盘

1. 左下角「日志设置」可改目录、设保留天数、打开日志目录。默认 `%APPDATA%\LANDrop\logs\landrop.log`。
2. 左下角「系统设置」可开「关闭窗口时最小化到托盘」和「开机自动启动」。
3. 托盘图标左键显示窗口，右键菜单可打开日志目录或退出。

```powershell
ssh -V

```

```powershell

icacls.exe "C:\ProgramData\ssh" /inheritance:r /grant "NT AUTHORITY\SYSTEM:(OI)(CI)(F)" /grant "BUILTIN\Administrators:(OI)(CI)(F)"
icacls.exe "C:\ProgramData\ssh\logs" /inheritance:r /grant "NT AUTHORITY\SYSTEM:(OI)(CI)(F)" /grant "BUILTIN\Administrators:(OI)(CI)(F)"

# 重启服务再验证 正常情况需要服务状态是running
Restart-Service sshd
Get-Service sshd
```
