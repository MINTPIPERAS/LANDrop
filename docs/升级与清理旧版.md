# 从 LANDrop 升级到 iRecon：旧版残留清理

iRecon 0.4.0 使用了全新的应用名称、安装标识和数据目录，**不会读取旧版 LANDrop 的任何配置**。本页说明如何卸载旧版，以及如何按需清理旧数据、凭据、定时任务和构建产物。

> 只想快速切换：**退出旧版，然后运行旧版卸载程序即可**。程序本体、快捷方式和卸载项会被清掉；旧用户数据会保留在 `%APPDATA%\LANDrop`，不影响 iRecon，只是继续占空间。想彻底清空再继续看第 2 节。

---

## 1. 最小清理：卸载旧版

1. 先退出正在运行的旧版：托盘图标右键 →「退出」。
2. 打开 `设置 → 应用 → 已安装的应用`，找到 **LANDrop** →「卸载」。
   - 也可以直接运行安装目录里的 `%LOCALAPPDATA%\LANDrop\uninstall.exe`。
   - 旧安装包保留在 `src-tauri\target\release\bundle\nsis\LANDrop_0.3.0_x64-setup.exe`，可用于回滚。
3. 卸载程序会删除：
   - `%LOCALAPPDATA%\LANDrop` 下的程序文件
   - 开始菜单 / 桌面快捷方式
   - Windows「应用和功能」中的卸载注册项
4. 卸载程序**不会删除**：
   - `%APPDATA%\LANDrop` 用户数据（配置、known_hosts、日志）
   - Windows 凭据管理器里的 SSH 密码
   - 计划任务 `LANDrop-*`
   - 开机自启注册表值 `LANDrop`（部分情况下会残留，建议按 2.6 检查）
   - 接收电脑上的 `*.landrop.part` 临时文件

完成这一步，旧版程序就不会再和新版同时运行；新版使用 `iRecon` 自己的目录和标识，两者互不干扰。

---

## 2. 彻底清理（逐项按需执行）

以下命令在 PowerShell 中执行。**删除操作不可恢复，执行前先确认路径。**

### 2.1 旧用户数据

位置：`%APPDATA%\LANDrop\`，通常包含：

- `config.json` — 接收电脑、快捷键、日志设置、定时任务
- `known_hosts` — 已信任的 SSH 主机指纹
- `logs\landrop.log*` — 旧日志
- `run.lock` / `service.log` — 运行残留

```powershell
# 先看看里面有什么
Get-ChildItem "$env:APPDATA\LANDrop" -Force

# 确认后删除
Remove-Item "$env:APPDATA\LANDrop" -Recurse -Force
```

> 旧密码不在这个目录里，而在 Windows 凭据管理器，见 2.4。

### 2.2 旧安装目录残留

如果卸载后目录仍然存在（文件被占用时常见）：

```powershell
Test-Path "$env:LOCALAPPDATA\LANDrop"
Remove-Item "$env:LOCALAPPDATA\LANDrop" -Recurse -Force
```

被占用时先重启电脑，或先在任务管理器结束旧的 `landrop-desktop.exe` / `landrop-service.exe`。

### 2.3 旧 WebView2 缓存

Tauri 的 WebView 数据目录可能包含旧的 localStorage/缓存，名字通常带 `landrop`：

```powershell
Get-ChildItem $env:LOCALAPPDATA -Directory |
  Where-Object { $_.Name -match 'landrop' } |
  Select-Object FullName
```

确认是旧应用目录后再删除：

```powershell
Remove-Item "<上面列出的目录>" -Recurse -Force
```

### 2.4 旧 SSH 密码凭据

旧版会在 Windows 凭据管理器写入两类目标名：

- `LANDrop/<host>:<port>/<username>`（当前格式）
- `LANDrop/<username>`（旧格式）

```powershell
# 列出所有包含 LANDrop 的凭据
cmdkey /list | Select-String 'LANDrop'
```

逐条删除（把目标名替换成上一步列出的完整名称）：

```powershell
cmdkey /delete:"LANDrop/192.168.1.5:22/lin"
cmdkey /delete:"LANDrop/lin"
```

也可以图形化操作：`控制面板 → 用户帐户 → 凭据管理器 → Windows 凭据`。

> 新版凭据前缀是 `iRecon/...`，不会读取这些旧条目。旧密码无法导出，只能在新版重新输入。

### 2.5 旧定时任务

旧版创建的任务名为 `LANDrop-<id前8位>`：

```powershell
# 查看
Get-ScheduledTask -TaskName 'LANDrop-*' | Format-Table TaskName, State

# 全部删除
Get-ScheduledTask -TaskName 'LANDrop-*' | Unregister-ScheduledTask -Confirm:$false
```

新版任务前缀为 `iRecon-*`。旧任务如果指向已卸载的旧 exe，会执行失败，建议删除。

### 2.6 旧开机自启

```powershell
# 查询（没有输出说明卸载程序已清理）
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name LANDrop -ErrorAction SilentlyContinue

# 删除
Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name LANDrop -ErrorAction SilentlyContinue
```

新版自启值名为 `iRecon`。

### 2.7 接收电脑上的旧临时文件

旧版断点续传的远端临时文件后缀是 `.landrop.part`，新版改为 `.irecon.part`，**不会续传旧文件**。到接收机的目标目录执行：

```bash
# 先列出
find ~/目标目录 -name '*.landrop.part' -print

# 确认后删除
find ~/目标目录 -name '*.landrop.part' -delete
```

### 2.8 仓库内的旧构建产物（开发机）

这些是生成物，可安全删除；旧安装包建议保留用于回滚：

```powershell
Remove-Item 'src-tauri\sidecar\landrop-service' -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item 'build\landrop-service' -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item 'src\landrop.egg-info' -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item 'src\landrop' -Recurse -Force -ErrorAction SilentlyContinue   # 重命名后只剩 __pycache__
```

如果以前执行过 `pip install -e .`，卸载旧的 Python 包，避免残留 `landrop-service` 命令：

```powershell
pip show landrop
pip uninstall landrop -y
```

## 3. 清理后检查清单

- [ ] `设置 → 应用` 中不再有 LANDrop
- [ ] `Test-Path "$env:APPDATA\LANDrop"` 返回 `False`
- [ ] `cmdkey /list | Select-String 'LANDrop'` 无结果
- [ ] `Get-ScheduledTask -TaskName 'LANDrop-*'` 无结果
- [ ] `HKCU:\Software\Microsoft\Windows\CurrentVersion\Run` 下无 `LANDrop`
- [ ] 接收机目标目录无 `*.landrop.part`
- [ ] 旧安装包按需保留（回滚用）

## 4. 新旧位置对照

| 项目 | 旧 LANDrop | 新 iRecon 0.4.0 |
|---|---|---|
| 安装目录 | `%LOCALAPPDATA%\LANDrop` | `%LOCALAPPDATA%\iRecon` |
| 配置文件 | `%APPDATA%\LANDrop\config.json` | `%APPDATA%\iRecon\config.json` |
| 主机指纹 | `%APPDATA%\LANDrop\known_hosts` | `%APPDATA%\iRecon\known_hosts` |
| 日志 | `%APPDATA%\LANDrop\logs\landrop.log` | `%APPDATA%\iRecon\logs\irecon.log` |
| Windows 凭据 | `LANDrop/<host>:<port>/<user>` | `iRecon/<host>:<port>/<user>` |
| 计划任务 | `LANDrop-<id>` | `iRecon-<id>` |
| 开机自启值 | `LANDrop` | `iRecon` |
| 远端临时文件 | `<文件名>.landrop.part` | `<文件名>.irecon.part` |
| 主程序 | `landrop-desktop.exe` | `irecon-desktop.exe` |
| 本地服务 | `landrop-service.exe` | `irecon-service.exe` |

---

## 5. 注意事项

- 建议**先卸载旧版，再安装 iRecon 0.4.0**。两版可以并存，但会各自启动 sidecar 和托盘图标，容易混淆。
- 卸载前先退出旧版托盘，否则文件占用可能导致卸载不完整。
- 不要把 `%APPDATA%\LANDrop` 里的 `config.json` 直接复制到 `%APPDATA%\iRecon`：新版配置模型不保证兼容，且旧密码无法随配置迁移。
- 回滚到旧版前，先备份 `%APPDATA%\iRecon`，并保留旧安装包。
- iRecon 运行期间不要删除 `%LOCALAPPDATA%\iRecon` 或 `%APPDATA%\iRecon`。
