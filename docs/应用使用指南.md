# LANDrop 应用使用指南

## 安装（普通用户）

拿到 `LANDrop_0.1.0_x64-setup.exe` 后双击安装即可。**目标机器不需要安装 Node.js 或 Python**，所有依赖都已打进安装包。

安装过程与普通 Windows 软件一致：安装包约 19 MB，安装后占用约 55 MB。安装位置默认在 `%LOCALAPPDATA%\LANDrop`，不需要管理员权限。

首次运行可能出现 Windows SmartScreen 提示（"Windows 已保护你的电脑"），这是因为安装包未做代码签名。点「更多信息」→「仍要运行」即可。

安装后的目录结构：

```
%LOCALAPPDATA%\LANDrop\
  landrop-desktop.exe          # 主程序，双击启动
  landrop-service\             # 内置的 Python 传输服务，不需要手动运行
  uninstall.exe                # 卸载程序
```

你的配置保存在 `%APPDATA%\LANDrop\config.json`，与安装目录分开。因此**卸载或覆盖升级都不会丢失已保存的连接配置**。

卸载：在 Windows「设置 → 应用」里找到 LANDrop 卸载，或直接运行安装目录里的 `uninstall.exe`。卸载会移除程序目录，但保留 `%APPDATA%\LANDrop` 下的配置。

## 启动与确认可用

**双击 `landrop-desktop.exe` 就是唯一需要的操作**（安装后可固定到开始菜单或桌面）。它会在后台自动拉起传输服务，不需要你手动运行任何 Python 或命令行。

启动后看窗口右上角：

- 显示「本机服务已连接」→ 一切正常，可以开始配置和传输。
- 显示「本机服务不可用」或一直停在"正在启动"→ 看 `%APPDATA%\LANDrop\service.log` 里的错误信息。

正常情况下**不会出现黑色命令行窗口**。如果你看到 cmd 黑窗一闪而过或常驻，那是旧版本的表现（sidecar 曾以控制台程序打包），重新安装当前版本即可。另外，如果你曾在项目目录跑过 `npm run dev`，那个 Vite 开发服务器也是独立的 cmd 窗口，与安装版无关，可以关掉。

任务管理器里会看到两个进程，这是正常的：

| 进程 | 作用 |
|---|---|
| `landrop-desktop.exe` | 主程序（窗口） |
| `landrop-service.exe` | 后台传输服务，由主程序管理，退出主程序时自动结束 |

## 从源码运行（开发）

在项目目录打开终端，运行：

```powershell
npm install
npm run tauri dev
```

这会同时启动桌面窗口和 Python 传输服务。首次启动需要几秒等待服务就绪，窗口右上角会显示「本机服务已连接」。

仅预览界面可运行 `npm run dev`，然后在浏览器打开 `http://127.0.0.1:1424`。浏览器模式没有桌面桥接，界面会提示「浏览器预览模式」，只能查看布局，无法选择真实文件或传输。

## 自己打包安装包

```powershell
npm install
python -m pip install -e ".[dev]"
npm run package
```

产物在 `src-tauri\target\release\bundle\nsis\LANDrop_0.1.0_x64-setup.exe`。

打包分两步：先用 PyInstaller 把 Python 服务打成 onedir 目录，再让 Tauri 把它收进安装包。`npm run package` 会按正确顺序执行并检查产物。

首次打包 Tauri 需要从 GitHub 下载 NSIS 工具链。如果网络访问不了 GitHub，会报 `timeout: global`，此时需要手动填充缓存，具体做法见[技术实现.md](技术实现.md) 第 12.4 节。

## 配置远端连接

1. 在「连接配置」中填写远端主机地址、SSH 端口、用户名和目标目录。
2. 选择认证方式：
   - **私钥**：点「浏览」指定私钥文件。留空只会去试 `ssh-agent` 和 `~/.ssh/id_rsa`、`id_ed25519` 这类默认文件名，本项目的 `landrop_ed25519` 不在其中，所以**必须显式指定**。**私钥不能设口令**，LANDrop 不支持带口令的私钥。
   - **密码**：直接输入；勾选「记住密码」后会保存到 Windows 凭据管理器，下次留空即可。只能用**账户密码**（不是锁屏 PIN）。接收端账户必须本地有可校验的密码：`Get-LocalUser <用户名> | Select PasswordRequired` 为 `True` 才行；微软账号或 PIN 免密账户通常为 `False`，只能改用密钥。
3. 点击「检查主机指纹」。界面会显示主机密钥类型和 SHA-256 指纹。
4. 首次连接某台远端时，确认指纹与服务器一致后点击「确认并保存」。未确认的主机不会建立传输。

需要生成密钥、或者远端是管理员账号（授权文件路径特殊）时，见 [SSH 密钥生成与配置](密钥生成.md)。

连接配置会保存到 `%APPDATA%\LANDrop\config.json`，其中不含密码。

## 发送文件

1. 在「新建传输」中点击文件选择框，选择要发送的单个文件。
2. 点击右侧发送按钮（或页面右上角「发送文件」）。
3. 任务面板会显示当前阶段：连接中、检查续传、传输中、校验中。
4. 传输期间连接配置被锁定，避免中途修改参数。

远端写入过程是：先写 `文件名.landrop.part`，完成后校验 SHA-256，一致才改名为最终文件。目标位置已有同名文件时不会静默覆盖，任务会失败并提示。

## 取消与重试

- 传输中可点击「取消」，远端 `.part` 会保留。
- 失败或取消后可点击「重试」。重试会重新连接并检查 `.part` 长度，从断点继续，不会重传已完成部分。
- 重试密码认证任务时，若未保存密码，需要重新填写。

## 全局快捷键

默认是 `Ctrl+Alt+Space`，用于把主窗口调到前台。应用启动时按配置自动注册。

**注意：热键的实际效果是把窗口显示出来并聚焦。** 如果 LANDrop 窗口本来就在最前面，按热键不会有任何可见变化——这是正常的，不是没响应。验证方法是先把窗口最小化，或切到别的程序，再按。

修改方式：点击左下角「设置全局快捷键」，在编辑器里点选修饰键（Ctrl / Alt / Shift / Win）、填写主键（如 `space`、`f9`、`k`），下方会实时显示最终组合，确认后点「应用」。

- 必须至少选择一个修饰键，否则会提示并保留原快捷键。
- 新快捷键若被其他程序占用，会回滚到原快捷键并提示，配置文件不会被改坏。
- 点击左下角头像可临时关闭或重新开启快捷键。
- 快捷键保存在 `%APPDATA%\LANDrop\config.json` 的 `hotkey_modifiers` / `hotkey_key` 字段。**升级或重装不会重置它**，如果你之前改过，装完仍是改过的值——想确认当前绑定，看界面左下角头像旁显示的文字。
- 浏览器预览模式下不注册快捷键，提示「仅桌面版支持快捷键」。

## 当前限制

- 只支持单文件发送，暂不支持多文件队列、目录递归传输和局域网设备发现。
- 只支持 SSH/SFTP 远端，需要远端已启用 OpenSSH Server。
- 目标目录必须是远端已存在且当前用户可写的目录。
- 安装包未做代码签名，首次运行会有 SmartScreen 提示。
- 暂无自动更新，升级需要下载新安装包覆盖安装。
