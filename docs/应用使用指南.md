# LANDrop 应用使用指南

## 安装（普通用户）

拿到 `LANDrop_0.2.0_x64-setup.exe` 后双击安装即可。**目标机器不需要安装 Node.js 或 Python**，所有依赖都已打进安装包。

安装过程与普通 Windows 软件一致：安装包约 19 MB，安装后占用约 55 MB。安装位置默认在 `%LOCALAPPDATA%\LANDrop`，不需要管理员权限。

首次运行可能出现 Windows SmartScreen 提示（"Windows 已保护你的电脑"），这是因为安装包未做代码签名。点「更多信息」→「仍要运行」即可。

安装后的目录结构：

```
%LOCALAPPDATA%\LANDrop\
  landrop-desktop.exe          # 主程序，双击启动
  landrop-service\             # 内置的 Python 传输服务，不需要手动运行
  uninstall.exe                # 卸载程序
```

你的配置保存在 `%APPDATA%\LANDrop\config.json`，与安装目录分开。因此**卸载或覆盖升级都不会丢失已保存的连接配置**。

卸载：在 Windows「设置 → 应用」里找到 LANDrop 卸载，或直接运行安装目录里的 `uninstall.exe`。卸载会移除程序目录，但保留 `%APPDATA%\LANDrop` 下的配置。

## 启动与确认可用

**双击 `landrop-desktop.exe` 就是唯一需要的操作**（安装后可固定到开始菜单或桌面）。它会在后台自动拉起传输服务，不需要你手动运行任何 Python 或命令行。

重复双击不会打开第二个窗口，而是把已经在运行的窗口调到前台。

启动后看窗口右上角：

- 显示「应用已就绪」→ 一切正常，可以开始配置和传输。
- 显示「启动失败」或一直停在「正在启动…」→ 看 `%APPDATA%\LANDrop\logs\landrop.log` 里的错误信息（设置里可改日志目录，也可点「打开目录」直达）。

正常情况下**不会出现黑色命令行窗口**。如果你看到 cmd 黑窗一闪而过或常驻，那是旧版本的表现（sidecar 曾以控制台程序打包），重新安装当前版本即可。另外，如果你曾在项目目录跑过 `npm run dev`，那个 Vite 开发服务器也是独立的 cmd 窗口，与安装版无关，可以关掉。

任务管理器里会看到两个进程，这是正常的：

| 进程 | 作用 |
|---|---|
| `landrop-desktop.exe` | 主程序（窗口） |
| `landrop-service.exe` | 后台传输服务，由主程序管理，退出主程序时自动结束 |

## 从源码运行（开发）

在项目目录打开终端，运行：

```powershell
npm install
npm run tauri dev
```

这会同时启动桌面窗口和 Python 传输服务。首次启动需要几秒等待服务就绪，窗口右上角会显示「本机服务已连接」。

仅预览界面可运行 `npm run dev`，然后在浏览器打开 `http://127.0.0.1:1424`。浏览器模式没有桌面桥接，界面会提示「浏览器预览模式」，只能查看布局，无法选择真实文件或传输。

## 自己打包安装包

```powershell
npm install
python -m pip install -e ".[dev]"
npm run package
```

产物在 `src-tauri\target\release\bundle\nsis\LANDrop_0.2.0_x64-setup.exe`。

打包分两步：先用 PyInstaller 把 Python 服务打成 onedir 目录，再让 Tauri 把它收进安装包。`npm run package` 会按正确顺序执行并检查产物。

首次打包 Tauri 需要从 GitHub 下载 NSIS 工具链。如果网络访问不了 GitHub，会报 `timeout: global`，此时需要手动填充缓存，具体做法见[技术实现.md](技术实现.md) 第 12.4 节。

## 配置远端连接

1. 在「接收电脑设置」中填写对方电脑的 IP 地址、SSH 端口、用户名和保存位置。
2. 选择认证方式：
   - **密码（推荐）**：直接输入；勾选「记住密码（下次不用再输入）」后会保存到 Windows 凭据管理器，下次留空即可。只能用**账户密码**（不是锁屏 PIN）。接收端账户必须本地有可校验的密码：`Get-LocalUser <用户名> | Select PasswordRequired` 为 `True` 才行；微软账号或 PIN 免密账户通常为 `False`，只能改用密钥。
   - **密钥文件**：点「浏览」指定私钥文件。留空只会去试 `ssh-agent` 和 `~/.ssh/id_rsa`、`id_ed25519` 这类默认文件名，本项目的 `landrop_ed25519` 不在其中，所以**必须显式指定**。**私钥不能设口令**，LANDrop 不支持带口令的私钥。
3. 点击「验证对方电脑身份」。界面会显示主机密钥类型和 SHA-256 指纹。
4. 首次连接某台远端时，确认指纹与服务器一致后点击「确认验证」。未确认的主机不会建立传输。最后点「保存这台电脑」。

需要生成密钥、或者远端是管理员账号（授权文件路径特殊）时，见 [SSH 密钥生成与配置](密钥生成.md)。

接收电脑设置会保存到 `%APPDATA%\LANDrop\config.json`，其中不含密码。

**多台远端**：侧栏「接收电脑」列表可以保存多台机器，点一下即切换。每台设备各自记住主机、端口、用户名、目标目录和认证方式；密码按「主机:端口/用户名」分开存在 Windows 凭据管理器里，不会互相覆盖。旧版本的单台配置首次启动会自动迁移成一个名为 `username@host` 的设备。

## 发送文件与文件夹

1. 在「发送文件」里点「选择」可以一次多选文件；右侧「选文件夹」按钮可以把整个目录加入队列。
2. 每加入一项都会出现在待发列表里，显示文件数、总大小；可以逐项移除，重复路径会自动去重。
3. 点「开始发送」（按钮显示「开始发送 N 项」）后按队列顺序逐个发送；某一项失败不会中断后续，失败的项会留在列表里。
4. 任务面板显示单文件阶段（正在连接对方电脑、检查断点、正在发送、正在核对文件）；文件夹任务额外显示「第 n/m 个文件」和当前文件名。**大文件校验会持续显示「正在核对文件 已核对/总量」**——这是两端各读一遍算 SHA-256，耗时大约是传输本身的一到两倍，不是卡住。
5. 远端写入过程是：先写 `文件名.landrop.part`，完成后校验 SHA-256，一致才改名为最终文件。文件夹会保留相对目录结构，空目录也会创建；保存位置不存在时自动逐级创建。
6. 目标已有同名文件时该项会失败并提示；批次结束后可点「覆盖并重发」，用原子改名替换已有文件。

## 取消与重试

- 传输中可点击「停止发送」，远端 `.part` 会保留。
- 队列发送中点「取消发送」会停止派发并取消当前任务；已完成的不受影响，未发的留在列表里。
- 失败或取消后可点击「重新发送」。重试会重新连接并检查 `.part` 长度，从断点继续，不会重传已完成部分。
- 重试密码认证任务时，若未保存密码，需要重新填写。

## 全局快捷键

默认是 `Ctrl+Alt+Space`，用于把主窗口调到前台。应用启动时按配置自动注册。

**注意：热键的实际效果是把窗口显示出来并聚焦。** 如果 LANDrop 窗口本来就在最前面，按热键不会有任何可见变化——这是正常的，不是没响应。验证方法是先把窗口最小化，或切到别的程序，再按。

修改方式：点击左下角「设置全局快捷键」，在编辑器里点选修饰键（Ctrl / Alt / Shift / Win）、填写主键（如 `space`、`f9`、`k`），下方会实时显示最终组合，确认后点「应用」。

- 必须至少选择一个修饰键，否则会提示并保留原快捷键。
- 新快捷键若被其他程序占用，会回滚到原快捷键并提示，配置文件不会被改坏。
- 点击左下角头像可临时关闭或重新开启快捷键。
- 快捷键保存在 `%APPDATA%\LANDrop\config.json` 的 `hotkey_modifiers` / `hotkey_key` 字段。**升级或重装不会重置它**，如果你之前改过，装完仍是改过的值——想确认当前绑定，看界面左下角头像旁显示的文字。
- 浏览器预览模式下不注册快捷键，提示「仅桌面版支持快捷键」。

## 日志

左下角「日志设置」里可以改日志目录、设置保留天数（7 / 14 / 30 / 90 天或永久），并查看当前占用、一键打开目录。

- 默认目录是 `%APPDATA%\LANDrop\logs\`，文件 `landrop.log`，按天滚动（`landrop.log.2026-11-06`），单个文件超过 10 MB 也会滚动。
- 记录服务启停、配置保存、每次传输的开始与结束（设备、路径、大小、耗时、SHA-256、错误码）。**不记录密码、令牌或私钥内容。**
- 超过保留天数的滚动文件会在启动时和每次保存配置后自动删除；`landrop.log` 本身不会被清掉。
- 目录不可写（比如移动盘拔掉）时只会停止写文件，不影响传输。

## 定时传输

左下角「定时传输」里可以新建一次性 / 每天 / 每周的定时发送任务，一个任务对应一个来源（文件或文件夹）。

- 应用运行时由内置调度线程到点执行，任务会出现在普通任务列表里，能看到进度。
- 应用关闭后由 Windows 计划任务执行：应用启动时会把启用的任务写进系统计划任务（当前用户、登录后运行、无需管理员），到点启动 `landrop-service.exe --run-schedule <id>` 无界面执行并写日志。
- 两套不会同时跑：GUI 服务运行期间持有 `run.lock`，计划任务那次会记录「跳过本次」后退出。
- 列表里显示下次运行时间；如果某个触发点错过了（应用没开、机器休眠），会标记「上次未执行」，可点「立即执行」补发。
- **到点执行的任务会出现在下方的任务列表里**，带一个「定时」标签，进度、结果、错误都可见；定时任务行的「上次」也会在几秒内自动刷新。
- 一次性任务的时间如果已经过去，保存时会被直接拒绝（避免建出一个永远不会触发的任务）。
- 一次性任务执行后自动停用并注销系统任务。触发时刻以本机时区为准，需要 Windows 处于登录状态。
- 密码认证的设备必须先勾选「记住密码」保存过密码，否则保存定时任务时会被拒绝——无人值守时没有地方输入密码。

## 托盘与开机自启

左下角「系统设置」里有两个开关：

- **关闭窗口时最小化到托盘**：开启后点关闭只是隐藏窗口，传输服务与定时任务继续运行；托盘图标左键可恢复窗口，右键菜单有「显示主窗口 / 打开日志目录 / 退出」。
- **开机自动启动**：写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，带 `--autostart` 静默启动到托盘。状态以注册表为准；如果程序换了安装位置，启动时会自动改写为当前路径。

卸载不会删除这个 Run 项，残留值指向已删除的路径时 Windows 会静默忽略；想彻底清掉可以在卸载前先关闭开关。

## 当前限制

- 队列不持久化：关闭应用后待发列表清空，重新添加即可（远端 `.part` 仍在，会续传）。
- 定时只有一次性 / 每天 / 每周三种；不支持「每隔 N 小时」「每月某天」「每月最后一天」。
- 只支持 SSH/SFTP 远端，需要远端已启用 OpenSSH Server。
- 安装包未做代码签名，首次运行会有 SmartScreen 提示。
- 暂无自动更新，升级需要下载新安装包覆盖安装。
