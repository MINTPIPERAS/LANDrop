# 局域网文件传输工具项目计划

本计划依据 [设计实现思路.md](设计实现思路.md) 制定，不设定日历时间。项目技术组合为 **Vue 3 + Tauri 桌面壳 + Python 本地传输服务**。按阶段推进；每阶段完成并通过检查后，再进入下一阶段。首版聚焦于 Windows 客户端向一台配置好的 SSH/SFTP 远端电脑发送单个文件。

## 阶段一：确认需求与开发环境

### 工作内容

- 确认首版只支持 Windows 桌面客户端、单文件发送和 SSH/SFTP 连接。
- 确认首版暂不包含多文件队列、目录传输、自动发现远端设备和开机自启。
- 准备 Python 3.11+、Node.js LTS、Rust stable、Git 及 Tauri 所需 Windows WebView2/构建工具。
- 确认至少有一台可用于测试的远端电脑，准备启用 OpenSSH Server。
- 建立前端、Tauri、Python 服务分别运行和测试的开发约定。

### 阶段交付与检查

- 明确首版需求范围和各技术子项目的启动/测试命令。
- 前端、Rust/Tauri、Python 开发环境均可运行。
- 有可用远端设备，或明确早期使用 mock 开发、后续再做集成验证。

## 阶段二：建立三部分工程骨架

### 工作内容

- 保留现有 Python 包、配置模块、Paramiko 传输核心与 pytest 测试。
- 新建 Vue 3 + TypeScript + Vite 前端工程。
- 新建 Tauri 2 桌面壳，配置开发模式窗口、最小 capabilities 和应用信息。
- 规划 Python sidecar 的启动入口与打包目录；暂不实现完整 UI 或发布打包。
- 更新根目录开发说明，写明前端、Tauri 和 Python 的分开启动方式。

### 阶段交付与检查

- Vue 开发服务器可运行，Tauri 开发模式可显示前端。
- Python 测试仍通过，前端和 Tauri 不依赖 PySide6。
- Tauri 仅开放当前需要的原生能力。

## 阶段三：本机 API 与 sidecar 生命周期

### 工作内容

- Python 服务实现 loopback HTTP API、随机端口、随机会话令牌和健康检查。
- Tauri Rust 层启动 Python sidecar，安全传递端口和令牌并管理其生命周期。
- 实现服务就绪检测、启动失败反馈和应用退出清理。
- 仅允许本机和受信任的应用来源访问；不提供任意文件读取或命令执行接口。

### 阶段交付与检查

- Vue 可通过 Tauri command 获得服务状态并调用健康检查。
- 无令牌、错误令牌和非 loopback 请求被拒绝。
- 关闭 Tauri 应用后 Python 子进程退出，不残留后台服务。

## 阶段四：传输核心 API 化

### 工作内容

- 将现有 `upload_file` 集成到 Python 任务管理器。
- 实现创建任务、查询状态、SSE 进度事件、取消和错误映射接口。
- 支持事件断线重连后查询任务快照；取消时保留远端 `.part`。
- 将连接凭据限制在任务请求的使用周期；密码持久化只能经 Windows Credential Manager。

### 阶段交付与检查

- API 测试覆盖任务创建、进度、取消、异常、重试和 SSE 重连。
- 现有传输 mock 测试继续通过。
- API 不绑定局域网网卡，敏感信息不进入日志或 URL。

## 阶段五：实现 Vue 主界面

### 工作内容

- 实现连接配置、认证方式、目标目录和主机指纹状态界面。
- 通过 Tauri 原生文件选择对话框选择发送文件。
- 实现发送、取消、进度、速度、阶段、错误详情和失败重试操作。
- 使用前端状态管理维护任务快照，处理 SSE 断线重连和状态同步。
- 传输期间锁定当前任务配置，避免修改运行中的连接参数。

### 阶段交付与检查

- 用户能在桌面窗口内完成配置、选文件、启动/取消任务并查看进度。
- 传输期间界面保持响应，断开事件流后可恢复显示正确状态。
- 前端不直接保存或记录密码、令牌，也不直接连接远端 SSH。

## 阶段六：全局快捷键与桌面集成

### 工作内容

- 使用 Tauri 的全局快捷键能力注册、更新和注销热键。
- 实现窗口显示、恢复与聚焦；处理热键冲突并降级为普通操作。
- 验证文件选择、应用退出、sidecar 清理和窗口关闭行为。
- 检查 Tauri capabilities，仅保留文件选择、窗口、快捷键和 sidecar 所需权限。

### 阶段交付与检查

- 窗口失焦时热键可唤起应用。
- 热键被占用时主界面和传输不受影响。
- 退出后快捷键注销，Python 服务及事件连接均清理。

## 阶段七：真实远端集成与安全验收

### 工作内容

- 配置 Windows OpenSSH Server；条件允许时增加 Linux OpenSSH Server 测试。
- 验证首次主机指纹确认、匹配与变化时的连接行为。
- 测试新传、取消后续传、网络中断恢复、目标冲突、认证失败和权限不足。
- 审查 loopback 绑定、随机端口、令牌校验、请求来源、日志和 Tauri 权限边界。
- 使用大于 4 GiB 文件验证传输并比对本地和远端 SHA-256。

### 阶段交付与检查

- Windows 客户端能与实际 SSH/SFTP 远端完成可靠传输。
- 断点续传仅发送剩余内容，完成文件哈希一致。
- 本地服务不能被局域网其他设备访问，错误场景不会暴露凭据。

## 阶段八：打包与发布准备

### 工作内容

- 构建 Vue 静态资源和 Tauri Windows 应用。
- 先将 Python 服务打包为 PyInstaller `onedir` sidecar，再由 Tauri bundle 收纳。
- 在未安装 Python/Node 的干净 Windows 环境验证安装、首次启动和传输。
- 明确用户配置、known_hosts、凭据保存位置及升级保留策略。
- 编写远端 OpenSSH 准备、连接信息获取、主机指纹确认和故障处理说明。

### 阶段交付与检查

- 发布包不依赖开发机的 Python/Node 环境。
- 安装、升级和退出行为可重复验证，升级保留用户配置。
- 卸载或退出不会留下无主 Python 服务进程。

## 后续增强（首版验收后再评估）

- 多文件队列和目录递归传输。
- 管理多台远端设备和多套连接配置。
- SSH 密钥管理与 Windows Credential Manager 凭据管理体验完善。
- 有上限的自动重试、速度限制和更详细的传输统计。
- 系统托盘、开机启动和安装程序体验优化。
- 局域网设备发现；若增加该功能，需单独评估发现协议和网络安全边界。

## 首版完成定义

- Windows Tauri 桌面应用通过 Vue 3 界面完成连接配置和单文件发送。
- Python sidecar 使用 Paramiko 连接用户配置的 SSH/SFTP 远端。
- 大文件可传输；中断后可从 `.part` 恢复，校验成功后才发布最终文件。
- 未知或变更的服务器主机密钥不会被静默接受。
- 本机 API 仅监听 loopback，带会话令牌且不能被局域网访问。
- UI 在传输过程中保持响应，支持进度、取消、失败和重试状态。
- 全局快捷键可用；冲突不会影响普通窗口和传输。
- 发布构建在未安装 Python/Node 的 Windows 环境中通过基本验收。
