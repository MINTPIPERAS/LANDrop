# 全新机器部署与验证

在干净的 Windows 上从零配好 LANDrop，并用一次真实传输证明它可用。**阶段 A 不需要第二台机器**，一条链路把密钥、sshd、授权文件、防火墙、目标目录全部验证一遍。

要求：Windows 10 1809 及以上。安装 LANDrop 不需要管理员，配置 sshd 和授权文件需要管理员。

## 0. 先确认角色

LANDrop 只负责"发"，**sshd 只在"收"的那台需要**。

| 这台机器的用途 | 要做的事 |
|---|---|
| 发文件给别的机器 | 阶段 A 全做 |
| 只收文件 | 阶段 A 的 A4–A8，不需要装 LANDrop |
| 双向互传 | 阶段 A + 阶段 B |

---

## 阶段 A：单机闭环验证

### A1. 安装 LANDrop

双击 `LANDrop_0.2.0_x64-setup.exe`，默认装到 `%LOCALAPPDATA%\LANDrop`。启动后右上角应显示「本机服务已连接」。显示不可用时看 `%APPDATA%\LANDrop\logs\landrop.log`。

### A2. 生成密钥

普通权限即可，Git Bash 或 PowerShell 都行：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/landrop_ed25519 -N "" -C "landrop@$(hostname)-$(date +%Y%m%d)"
```

`-N ""` 不能省：LANDrop 不支持带口令的私钥，带口令会直接报 `PasswordRequiredException`。

产物两个：

```
~/.ssh/landrop_ed25519       # 私钥，411 字节左右，绝不外传
~/.ssh/landrop_ed25519.pub   # 公钥，可以随便给
```

### A3. 收紧私钥权限

私钥对其他账户可读时 OpenSSH 会拒绝使用。PowerShell：

```powershell
$key = Join-Path $env:USERPROFILE '.ssh\landrop_ed25519'
$acl = New-Object System.Security.AccessControl.FileSecurity
$acl.SetAccessRuleProtection($true, $false)
$me  = [System.Security.Principal.WindowsIdentity]::GetCurrent().Name
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule($me,'FullControl','Allow')))
Set-Acl -Path $key -AclObject $acl

(Get-Acl $key).Access | ForEach-Object { $_.IdentityReference.ToString() + '  ' + $_.FileSystemRights }
```

最后一行只剩你自己一条就对了。别用 `icacls ... /grant:r "$env:USERNAME:(R)"`，Git Bash 会把 `(R)` 当语法吃掉。

### A4. 装并启动 sshd

管理员 PowerShell：

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
Get-Service sshd
netstat -ano | findstr ":22 "
```

`Status` 要是 `Running`、`StartType` 要是 `Automatic`，且能看到 `0.0.0.0:22 ... LISTENING`。首次启动会自动在 `C:\ProgramData\ssh\` 下生成主机密钥。

> 机器不能上网时，`Add-WindowsCapability` 会失败。改走「设置 → 应用 → 可选功能 → 添加功能 → OpenSSH 服务器」，同样需要能访问 Windows Update 或本地 FoD 源。

### A5. 防火墙

```powershell
Get-NetFirewallRule -Name OpenSSH-Server-In-TCP | Select-Object Enabled,Profile,Direction,Action
```

正常是 `True / Any / Inbound / Allow`。**如果 Profile 只写了 `Private` 而当前网络是 `Public`，入站包会被静默丢弃**，表现是连接超时。查网络分类：

```powershell
Get-NetConnectionProfile
```

信任的家里/办公局域网，直接改分类最省事（`-InterfaceAlias` 填上一步 `Get-NetConnectionProfile` 里显示的网卡名，常见是 `WLAN`、`以太网` 或 `Wi-Fi`）：

```powershell
Set-NetConnectionProfile -InterfaceAlias "WLAN" -NetworkCategory Private
```

规则不存在时才新建（注意 `-Profile Any`）：

```powershell
New-NetFirewallRule -Name OpenSSH-Server-In-TCP -DisplayName 'OpenSSH SSH Server (sshd)' `
  -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22 -Profile Any
```

### A6. 判断授权文件位置

Windows OpenSSH 对**管理员组**用另一个授权文件，写错地方不报错、只是永远认证失败：

```powershell
whoami
whoami /groups | findstr /i "S-1-5-32-544"
```

- 第二条**有输出**（含 `S-1-5-32-544`）→ 管理员账号 → `C:\ProgramData\ssh\administrators_authorized_keys`
- **无输出** → 普通账号 → `C:\Users\<用户名>\.ssh\authorized_keys`

顺手确认 `C:\ProgramData\ssh\sshd_config` 里 `PubkeyAuthentication yes`，改过就 `Restart-Service sshd`。

### A7. 写入公钥

**管理员账号**（管理员 PowerShell，自测时就是自己的公钥）：

```powershell
$pubKey   = (Get-Content (Join-Path $env:USERPROFILE '.ssh\landrop_ed25519.pub') -Raw).Trim()
$authFile = 'C:\ProgramData\ssh\administrators_authorized_keys'

if (-not (Test-Path $authFile)) { New-Item -ItemType File -Path $authFile -Force | Out-Null }
Add-Content -Path $authFile -Value $pubKey -Encoding ascii

$acl = New-Object System.Security.AccessControl.FileSecurity
$acl.SetAccessRuleProtection($true, $false)
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule('BUILTIN\Administrators','FullControl','Allow')))
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule('NT AUTHORITY\SYSTEM','FullControl','Allow')))
Set-Acl -Path $authFile -AclObject $acl
```

**普通账号**：

```powershell
$pubKey   = (Get-Content (Join-Path $env:USERPROFILE '.ssh\landrop_ed25519.pub') -Raw).Trim()
$authFile = Join-Path $env:USERPROFILE '.ssh\authorized_keys'

New-Item -ItemType Directory -Path (Split-Path $authFile) -Force | Out-Null
Add-Content -Path $authFile -Value $pubKey -Encoding ascii
```

### A8. 建目标目录

LANDrop 不会自动建目录：

```powershell
New-Item -ItemType Directory -Path 'D:\LANDropTest' -Force
```

### A9. 命令层验证

先别开界面，用 OpenSSH 确认认证链路通了：

```bash
ssh -i ~/.ssh/landrop_ed25519 -o BatchMode=yes -o StrictHostKeyChecking=accept-new <用户名>@127.0.0.1 "echo KEY_LOGIN_OK && whoami"
```

`BatchMode=yes` 禁止密码回退，成功即证明是**纯密钥**通过。看到 `KEY_LOGIN_OK` 和下面一行用户名再往下走；这一步报错的话别碰界面，按文末对照表解决。

> Windows 目标机的默认 shell 是 cmd，串联命令用 `&&`。写成 `;` 只会把整串原样打印出来，看起来像成功、其实 `whoami` 没执行。

### A10. 界面验证

1. 「连接配置」填：远端主机 `127.0.0.1`、SSH 端口 `22`、用户名（`whoami` 输出的反斜杠后半段，如 `ASUS`）、目标目录 `D:/LANDropTest`、认证方式「私钥」、私钥路径 `C:\Users\<你>\.ssh\landrop_ed25519`。
   **私钥路径必须填，不能留空**——留空只会去找 `ssh-agent` 和 `~/.ssh/id_rsa`、`id_ed25519` 这类默认文件名，`landrop_ed25519` 不在其中。
2. 点「检查主机指纹」，与下面这条命令的输出比对，一致才点「确认并保存」：

   ```powershell
   ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ed25519_key.pub
   ```

3. 选一个几 MB 的文件发送。
4. 比对两端哈希，一致即验收通过：

   ```powershell
   Get-FileHash 'D:\LANDropTest\<文件名>' -Algorithm SHA256
   Get-FileHash '<源文件路径>'                 -Algorithm SHA256
   ```

## 阶段 B：接第二台机器

1. 两边各做一遍阶段 A，各自有自己的密钥对和 sshd。
2. 各自把 `~/.ssh/landrop_ed25519.pub` 那一行发给对方（**不要发没有 `.pub` 的私钥**），对方按 A6/A7 装进去——把 A7 里的 `$pubKey` 换成收到的那一行即可。
3. 发送方把远端主机改成对方当前 IP。**IP 会变，每次发送前重查**：

   ```powershell
   Get-NetIPAddress -AddressFamily IPv4 |
     Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } |
     Select-Object InterfaceAlias, IPAddress
   ```

   选实际联网那块网卡（`WLAN` / `以太网` / `Wi-Fi`），VMware、VirtualBox、LetsTAP 之类的虚拟网卡忽略。

4. 核对指纹：对方执行 `ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ed25519_key.pub`，两边显示一致才点「确认并保存」。
5. 发送并比对哈希（同 A10 第 4 步）。

目标目录即使对方是 Windows 也用正斜杠，例如 `C:/Users/<对方>/Downloads`，且必须是已存在、当前用户可写的目录。

## 报错对照

| 报错 | 含义 | 处理 |
|---|---|---|
| `timed out` | 目标 IP 上没有主机应答 | 地址过期、防火墙 Profile 不匹配、不在同一网段。重查 IP，按 A5 查规则 |
| `Connection refused` | 主机在，22 端口没开 | 目标机 `Get-Service sshd` |
| `Permission denied (publickey)` | 公钥没装对位置，或授权文件 ACL 不对 | 按 A6 判断路径，按 A7 重写 |
| `Load key: invalid format` | 私钥路径填成了 `.pub` | 填没有后缀的那个 |
| `PasswordRequiredException` | 私钥设了口令 | `-N ""` 重新生成 |
| `UNPROTECTED PRIVATE KEY FILE` | 私钥权限过宽 | 按 A3 收紧 |
| 认证通过但传不动 | 目标目录不存在或不可写 | 按 A8 建目录 |
| 提示目标文件已存在 | 不静默覆盖 | 换文件名或先删远端同名文件 |
| 密码认证一直失败 | 微软账号本地没有 NTLM 哈希 | 只能用密钥 |

## 速查

| 项目 | 位置 |
|---|---|
| 安装目录 | `%LOCALAPPDATA%\LANDrop` |
| 连接配置 | `%APPDATA%\LANDrop\config.json`（不含密码） |
| 已确认主机 | `%APPDATA%\LANDrop\known_hosts` |
| 服务日志 | `%APPDATA%\LANDrop\logs\landrop.log`（按天滚动，保留天数可配，目录可改） |
| 传输历史 | 内存态，重启清空；传输成败记在日志里 |
| sshd 主机密钥 | `C:\ProgramData\ssh\ssh_host_ed25519_key` |

查自己的对端参数（别人连你时要这些）：

```powershell
whoami
ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ed25519_key.pub
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } |
  Select-Object InterfaceAlias, IPAddress
```
