# LANDrop 概要

一页纸速查：这是什么、怎么运作、怎么用、还差什么。细节见各专项文档。

## 一、这是什么

Windows 桌面工具，把本机单个文件通过 **SSH/SFTP** 发送到另一台电脑。适合局域网内传大文件，支持断点续传和 SHA-256 校验。

不是 P2P 直传工具：远端必须运行 SSH 服务（OpenSSH Server），LANDrop 只负责把文件可靠地写过去。

**技术栈**：Vue 3（界面）+ Tauri 2/Rust（桌面壳）+ Python/Paramiko（传输）。

## 二、原理

三层拆分，各管一件事：

```
Vue 3 WebView        界面、表单、进度显示
      ↓ invoke / HTTP + SSE
Tauri 2 / Rust       起停 Python 服务、随机端口+令牌、窗口、热键
      ↓ 环境变量传端口与令牌
Python + Paramiko    真正的 SSH/SFTP 传输，只监听 127.0.0.1
      ↓
远端 SSH 服务器
```

**为什么这么分**：WebView 拿不到裸 TCP，也不该持有私钥和密码；前端无权创建进程和回收子进程；已有可用的 Paramiko 传输核心（`.part` 续传、哈希校验、主机密钥拒绝），复用比重写更稳。

### 一次传输的关键设计

| 环节 | 做法 |
|---|---|
| 写入 | 先写 `文件名.landrop.part`，完成后才改名为正式文件 |
| 续传 | 读远端 `.part` 长度，本地 `seek` 到该位置，追加写 |
| 校验 | 两边各算一次 SHA-256，一致才发布 |
| 覆盖 | 默认拒绝；显式覆盖走原子 `posix_rename`，不支持就报错 |
| 主机身份 | 首次连接必须用户确认指纹，未知/变更一律拒绝 |
| 进度 | SSE 推送，断线可用 `Last-Event-ID` 续接 |
| 本地 API | 仅 `127.0.0.1`，每次启动新令牌，校验来源 |

配置文件在 `%APPDATA%\LANDrop\config.json`，私钥留在本地，密码只在 Windows 凭据管理器。

## 三、怎么用

### 普通使用

1. 安装 `LANDrop_0.2.0_x64-setup.exe`（19.4 MB，目标机不需要 Python/Node）
2. 双击启动，右上角显示「本机服务已连接」
3. 填远端信息：IP、端口 22、用户名、目标目录（**用正斜杠** `D:/`；目录不存在会自动创建，含子目录）
4. 认证方式选**私钥**，指向私钥文件（**不带 `.pub`** 的那个）
5. 点「检查主机指纹」，与远端 `ssh-keygen -lf` 的输出核对一致后「确认并保存」
6. 选文件或文件夹 → 发送（文件夹会保留相对目录结构）

全局快捷键默认 `Ctrl+Alt+Space`，窗口最小化或失焦时按它唤起。可在左下角「设置全局快捷键」修改。

### 远端准备（对方电脑）

1. 启用 OpenSSH Server：`Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0`
2. 启动服务：`Set-Service sshd -StartupType Automatic; Start-Service sshd`
3. **放行防火墙**：`New-NetFirewallRule -Name "OpenSSH-Server-In-TCP" -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22 -Profile Any`
4. 安装发送方的**公钥**到：
   - 管理员账号 → `C:\ProgramData\ssh\administrators_authorized_keys`
   - 普通账号 → `~\.ssh\authorized_keys`
5. 接收目录可预先建好；不建也会在首次发送时自动创建（含多级子目录）

### 排错顺序（按错误类型判断）

| 错误 | 含义 | 先查 |
|---|---|---|
| `无法访问目标主机` | 网络层不通 | IP 是否过期、是否同网段 |
| `timed out` | 包被丢弃 | **防火墙规则 Profile 是否匹配网络类型** |
| `Connection refused` | 端口没监听 | sshd 是否 Running |
| `Permission denied (publickey)` | 认证失败 | 公钥装的位置、私钥路径是否填了 |
| `PasswordRequiredException` | 私钥带口令 | LANDrop 不支持，重生成无口令密钥 |

> 最常见的坑：防火墙规则的 `Profile` 是 `Private`，但网络被识别成 `Public`，导致规则不生效、表现为超时。

## 五、需要补齐的功能

按建议优先级排序：

| 优先级 | 功能 | 说明 |
|---|---|---|
| 二期已完成 | **多文件队列** | 一次多选入队、串行发送；单项失败不阻断后续，失败项可一键覆盖重发 |
| 二期已完成 | **覆盖确认** | 失败项可「覆盖并重发」，复用后端已有的原子 `posix_rename` |
| 二期已完成 | **日志与保留策略** | 默认 `%APPDATA%\LANDrop\logs`，目录可改、按天滚动、保留天数可配（0 = 永久） |
| 二期已完成 | **目录递归传输** | 选文件夹发送，保留相对结构，单文件失败不中断整批 |
| 中 | **真实主机验收** | 尚未在 >4 GiB 文件、Linux 远端上做过完整验证 |
| 二期已完成 | **多设备记忆与切换** | 侧栏保存多台设备并一键切换，旧配置自动迁移成第一台 |
| 低 | 代码签名 | 安装包未签名，首次运行有 SmartScreen 提示 |
| 低 | 自动更新 | 升级需手动下载安装包 |
| 低 | 速度限制 / 传输后删源文件 | 无 |
| 二期已完成 | **定时传输** | 一次性 / 每天 / 每周；应用内调度与 Windows 计划任务两路互斥执行 |
| 二期已完成 | **系统托盘 / 开机自启** | 关窗最小化到托盘；注册表 Run 项开机自启，启动路径自动修正 |

明确不做：局域网设备发现、NAT 穿透。
